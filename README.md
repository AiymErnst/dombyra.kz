# dombyra.kz — новый сайт (Next.js)

Стартовый скелет для переезда с Тильды. Стек: Next.js (App Router) + Tailwind CSS.
Дальше — Vercel (хостинг) + Supabase (БД/авторизация/файлы), как обсуждали.

## Что уже есть

- `app/page.js` — главная (заглушка, контент перенести с текущего сайта)
- `app/simulator/page.js` — страница `/simulator`, встраивает `public/simulator.html`
  через iframe (быстрый вариант, шаг 1 из плана миграции)
- `public/simulator.html` — текущий тренажёр домбры, перенесён как есть
- `app/components/SiteHeader.jsx`, `SiteFooter.jsx` — общая шапка/подвал
- `app/globals.css` — фирменные цвета (вино/золото) и шрифты (Marcellus/Manrope)

## Запуск локально

```bash
npm install
npm run dev
```
Открыть http://localhost:3000

## Деплой на Vercel

1. Запушить этот репозиторий на GitHub
2. На vercel.com → Add New Project → выбрать репозиторий → Deploy
   (Next.js определится автоматически, ничего настраивать не нужно)
3. Когда всё проверено на `*.vercel.app` — подключить домен dombyra.kz
   в настройках проекта (Vercel сам покажет, какие DNS-записи добавить
   у регистратора)

## Следующие шаги (не входят в этот скелет)

1. **Перенести контент** остальных страниц сайта с Тильды
2. **Тренажёр → React**: переписать `public/simulator.html` в нормальный
   React-компонент (сейчас это просто iframe — работает, но не даёт
   SEO и не может напрямую писать в Supabase)
3. **Supabase**: подключить проект, создать таблицы под мелодии
   (`songs`, `tags`, `song_tags`), пользователей и т.д.
4. **Админка**: начать со встроенной Supabase Table Editor,
   свою страницу `/admin` делать вторым шагом
5. **Мелодии в базу**: перенести массив `songs` из тренажёра в таблицу
   Supabase вместо хардкода в файле
